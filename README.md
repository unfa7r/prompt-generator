# Visionary

An interactive Python-based AI scene and prompt generator.

## Installation

### Termux
    pkg update && pkg upgrade -y
    pkg install python git -y
    git clone https://github.com/unfa7r/prompt-generator.git
    cd prompt-generator
    python visionary.py

### Linux
    sudo apt update
    sudo apt install python3 git -y
    git clone https://github.com/unfa7r/prompt-generator.git
    cd prompt-generator
    python3 visionary.py
